# FITLOG

FITLOG is a modern workout management web application built with Next.js. It helps users explore different workouts, view detailed workout information, create a personal workout plan, and save workouts for later.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- REST API
- LocalStorage

## Key Features

1. **Workout Library**
   - Browse and explore a collection of different workouts.

2. **Workout Details**
   - View detailed workout information including muscle groups, difficulty, duration, calories, rating, equipment, sets, reps, and instructions.

3. **My Plan**
   - Add workouts to a personal daily workout plan and remove them when needed.

4. **Save for Later**
   - Save workouts and access them later from the Saved section.

5. **Workout Sorting**
   - Sort workouts by duration or calories burned for easier planning.
